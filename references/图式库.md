## 1. 钉子（Nail）

- **一句话用途**：在一张"趋势/对比"图上，把**关键的那一个点**钉出来并标注 —— 让读者别去找，直接看结论。
- **核心想法**：不是画满数据，而是**钉住结论**。典型：一条训练/评估曲线 + 一个"钉子"（竖杆 + 圆头/倒三角）钉在"达标点"上，旁边写「381 步 / 92.1%」。变体：**钉子矩阵**（每个方法一行，各自钉一个点）；**时间轴钉**（创新点钉在时间轴/流程轴上）。
- **怎么画**：`ax.annotate` + 一段竖线（`ax.vlines` 或 `plot([x,x],[y0,y])`）+ 端点标记（圆头/倒三角）+ 短文字。
- **代码骨架**：`mpl_style.nail(ax, x, y, text, base=0)`（base=竖杆起点，默认轴下沿）
- **红线**：
  - **一张图最多 3 个钉子** —— 超过就是噪音，拆图或用别的图式；
  - 钉子指的位置必须**有数据点**（别钉在插值/平滑曲线上）；
  - 钉子的文字要含**口径**（`20 runs`），否则不同图不可比。

## 2. 阶梯（Staircase）

- **一句话用途**：讲**分阶段抬升** —— 每一级"平段"是稳定期，"竖直段"是那次改动带来的跃升。
- **核心想法**：横轴 = 轮次/阶段，纵轴 = 指标；用 `step(where='post')` 画；
  关键是**在竖直段标出事件**（如「+ SmoothL1」「+ 认知奖励」），横段标**持续轮数**。
  常用变体：**双阶梯对比**（基线 vs 本文各一条，台阶高度差 = 收益）；**反向阶梯**（性能随步数预算阶梯下降）。
- **怎么画**：`ax.step(xs, ys, where='post', marker='o')` + 在竖直段加箭头与事件标签。
- **代码骨架**：`mpl_style.staircase(ax, xs, ys, events={i: "标签"})`
- **红线**：
  - **台阶必须来自真实的离散事件**（课程阶段、超参切换）—— 把平滑曲线硬掰成台阶＝造图；
  - 台阶的**横段长度**要如实反映轮数，别为了好看拉长；
  - 对比两条阶梯时**共享纵轴**。
- **实例**：_（待补：γ/损失消融的跃升、课程学习阶段表）_

## 3. 滑轴（Sliding axis）

- **一句话用途**：**同一张图里解决尺度问题** —— 全貌要看，尾部/头部细节也要看清。
- **核心想法**：三种做法：
  ① **断轴**（broken axis）：跳过中间大片空白，左段+右段拼接（如损失 0–2 与 80–100）；
  ② **尾窗放大**（滑窗）：主图画全程，右端接一个"放大窗"把最后 200 轮的差异拉出来；
  ③ **并排滑轴**（共享纵轴）：横轴按尺寸/机数**滑动**切段（30→45→60），纵轴不变 → 直接可比。
- **怎么画**：`GridSpec` 两个无缝子图 + 隐藏相邻 spine + 画**断口斜线符号**（`//`）；或 `inset_axes` 做放大窗。
- **代码骨架**：`mpl_style.sliding_axis(fig, rect_left, rect_right, break_marks=True)`
- **红线**：
  - 🔴 **断轴必须画断口符号 + 标注两段区间**，否则是**误导性作图**；
  - 两段**不要**各自归一化纵轴（除非明确标注）；
  - 并排滑轴时**共享色标/纵轴**（同 `vmin/vmax`）。
- **实例**：_（待补：不同规模组的"同纵轴并排"；收敛尾窗放大）_

## 4. 魔方串烧（Cube skewer）

- **一句话用途**：把**多张"方块"串成一条线**讲演化 —— 一块 = 一个 3D 网格/热力快照（覆盖图、势场图），一根"签子"贯穿。
- **核心想法**：一行（或一列）**等距小方块**，每块是同一坐标系下的快照（如 30×30 覆盖热力图），
  块间用箭头/时间轴串起并标阶段（`t=0 → 50% → 92%`）；必要时每块角上放**序号/轮次标签**。
- **怎么画**：`GridSpec(1, N)`，每格 `imshow(grid, cmap, vmin=0, vmax=1)`；**只有最后一格（或底部共用）一个 colorbar**；用 `annotate` 画贯穿箭头。
- **代码骨架**：`mpl_style.cube_skewer(fig, grids, titles=[...], cmap='viridis', vmin=0, vmax=1)`
- **红线**：
  - 🔴 **每块必须共用 `vmin/vmax` 和 cmap** —— 否则"看起来对、其实不能比"（经典造图事故）；
  - **块数 4–6 为宜**（>6 就缩小到看不清，改成分组或动画）；
  - 方块里的**障碍物/边界**要一致，否则读者以为地图变了。
- **实例**：_（待补：同一策略在不同规模上的覆盖快照串烧；训练演化）_

## 5. 横排对照（Horizontal grouped bar + Δ column）

- **一句话用途**：**当"类别名"很长（中文全名 + 参数）时，把对比类别搬到 y 轴** ——
  纵向柱状图的 x 轴刻度只有几厘米宽，10 个长中文名必然互相压字（实测踩过：`k6｜目标数 K=6` 与相邻标签重叠）；
  横向 `barh` 的 y 轴"要多少宽度有多少"，名字可以写全，不用缩写。
  并在**行末加一列 Δ**（两条件之差），把"漂移/提升"直接写成数字 —— 比在两柱之间画箭头更准，也不压柱子。
- **怎么画**：
  1. `ax.barh(yi, v, height=h, hatch=…, edgecolor='black')`，两个条件用 `hatch=None` / `'///'` 区分
     （**实心 vs 斜纹**：色盲安全，灰度也能辨，不要靠深浅同色系）；
  2. `ax.invert_yaxis()` 让类别按给定顺序**从上到下**；
  3. 数值标签放在柱右，**必须加白底 bbox**（`bbox=dict(facecolor='white', alpha=0.8, edgecolor='none')`），
     否则会被相邻的长柱盖住；
  4. 行末 Δ 用 `ax.text(xlim*0.985, i, "ΔT92 +41% · Δ成功率 -40pp", ha='right', color='#666')`；
  5. 图例放轴外（`bbox_to_anchor=(0.5,-0.10), ncol=2`），别和图内元素抢位置。
- **代码骨架**：无专用函数（约 40 行，照上面 5 步写即可）。
- **红线**：① **口径必须先定**——柱长要用"只统计有效样本"的量（如只算达标轮），
  把含失败样本的均值（会被上限截断拉高）换掉，并在轴标签里写明；
  ② 缺数据的类别**标注"未提交/无数据"**，绝不留空柱（空柱会被读成 0）；
  ③ Δ 要做**方向中立**的写法（`+x%` 而不是"提升 x%"）—— 差异可能是**双向**的。
- **实例**：
  - 2026-09-20 · 多场景验证实验 · 10 个对比试验 × 2 seed 的达标步数：实心 seed-0 / 斜纹 seed-1，行末给出 ΔT92 与 Δ成功率；
    **一眼看出重复臂漂移（+12.5%~+151.5%）已和跨场景差异同量级**。
